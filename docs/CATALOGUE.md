# Story catalogue

Library identifies a release by its Z-machine version, release number, six-byte serial and checksum after header validation. It does not guess from renamed filenames. The compiled header table never identifies a file whose internal checksum fails. The optional cached online catalogue can still identify an exact published file by its full-file digest; the checksum warning remains visible. The original filename, release details and any warning stay available in the picker and full details.

`assets/story-catalog.json` contains 68 entries: the original recognised releases, 24 additional release fingerprints from the updated collection, and five original demonstration builds. The private stories themselves are not included. `scripts/prepare_catalog.py` validates unique fingerprints and generates the compiled table during CMake configuration. Normal startup uses this compiled table offline. The optional [Online Library](ONLINE_LIBRARY.md) can fetch an external catalogue on request. Its cached metadata identifies other downloaded releases by full-file MD5 plus matching version/release/serial; it survives a rename. Unrecognised or differently patched releases retain their filenames and a clear no-verified-synopsis message.

The historical release identities and unusual editions were checked against [Andrew Plotkin's Infocom catalogue](https://eblong.com/infocom/). Summaries are original, brief, spoiler-free descriptions rather than copied story text or catalogue descriptions. Catalogue data and the original synopsis wording are provided under GPL-3.0-or-later with this application.

Special editions are labelled explicitly: the generic story template, interpreter tests, sampler, unfinished Restaurant prototype and gamma builds are not presented as ordinary finished adventures. The Hypochondriac group includes two modified Enchanter releases, a modified Zork experiment, and Hypochondriac itself; those are labelled separately. The Abyss and both Restaurant builds are unfinished prototypes. The updated Hitchhiker r60 is labelled as an unreleased final-dev build, and Mini-Zork II notes its reported Carousel Room compatibility problem. Matching a release does not certify its playability or provide missing media.

To add another release, supply its exact public header fingerprint, verified title, edition, short original synopsis and identity source in the JSON file. Reconfigure/build, check the actual picker at 320×170, and keep game code, transcripts and personal file paths out of the catalogue. Local `--inventory` output includes title, synopsis and edition alongside header information; it is private diagnostic output, not a release input.

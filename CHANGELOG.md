# Changelog

The package version adds Debian revision `-1` to the application version. These versions were developed and tested on 19–20 November 2026; publication to the source repository is separate from store submission. See [verification results](docs/TEST_RESULTS.md) for measured evidence and limits.

## 0.8.1 — 20 November 2026

- Replaced sequential Controls paragraphs with Reading, Game controls, Menus, Saves and Keyboard topics.
- Added larger shortcut/action rows, complete-row paging and consistent back navigation in both themes.
- Kept the story screen and unfinished command intact when returning from in-game help.

## 0.8.0 — 20 November 2026

- Made Automatic the default for all supported V3–V8 stories, using the chosen reading size.
- Added a one-time migration of old display preferences while preserving later manual choices.
- Preserved text/original-layout selection through supported Continue saves; retained frontend schema 2–7 compatibility.
- Improved upper-window text capture and interpreter More-pause checkpoint safety.

## 0.7.0 — 20 November 2026

- Added Automatic fitted artwork/readable text for V6 games, including timed text.
- Shortened code-author credits and standardised author/maintainer details as Ahazi.

## 0.6.0 — 20 November 2026

- Made title/intro key pauses readable, including Trinity's opening.
- Added Frame + Text Zoom, confirmed title deletion with saves retained, and named-save load/rename/delete management.

## 0.5.0 — 20 November 2026

- Added Reader, Fit, Fill, Fit Width, Actual Pixels and Reading Zoom views.
- Simplified home/story navigation and added full arrow/number navigation.
- Added IF Archive downloads, supported ZIP bundles and embedded/local story artwork.

## 0.4.0 — 20 November 2026

- Added the book-and-lantern identity, launcher icon, adventure artwork and offline credits.

## 0.3.0 — 20 November 2026

- Added the Infocom Online Library, cached notes and manual/website links with QR codes.
- Matched separate Blorb media by release identity or embedded code hash.

## 0.2.1 — 20 November 2026

- Remapped primary shortcuts to Ctrl plus one plain physical key on the Zero.

## 0.2.0 — 20 November 2026

- Added the first home-screen redesign, title/synopsis library and live reading-size controls.

## 0.1.0 — 19–20 November 2026

- Integrated pinned graphical Frotz, desktop/device rendering, story loading, portable saves and supported prompt-boundary Continue.
- Added history, scrollback, graphics/audio fixtures, packaging and Windows deployment tools.
